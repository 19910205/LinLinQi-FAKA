# LinLinQi 功能矩阵

## 用户与身份

- 游客购买、邮箱订单查询、用户注册/登录、账户资料、订单、钱包和工单
- 访问令牌与旋转刷新令牌、设备会话、退出撤销、登录事件模型
- 会员等级、累计消费门槛、等级折扣、手工授予和有效期
- OAuth 身份映射、TOTP 数据结构与安全事件留痕

## 商品与库存

- 分类、商品、SKU/规格、上下架、排序、标签、成本价与划线价
- 本地卡密、供应库存、批次导入、去重指纹、库存预警、卡密预览
- 阶梯价格、会员价、批发价、商品允许支付渠道和购买数量限制
- 购物车、多商品结算、商品级动态下单字段（账号/UID/区服/下拉/正则）、加密订单值、商品映射和同步状态

## 订单、支付与交付

- 待支付、风控复核、处理、交付、失败、退款和完成状态机
- PostgreSQL 行锁与 `SKIP LOCKED`，同一事务预占多商品库存
- 支付意图、支付流水、签名回调、金额匹配、事件唯一约束和支付超时
- 本地卡密加密交付、供应采购模型、交付尝试、失败原因与订单事件
- 退款单、渠道退款号、对账批次、差异项和人工解决记录

## 营销与增长

- 优惠券、促销规则、商品范围、优先级、可叠加配置和活动有效期
- 礼品卡发行、哈希卡号、余额流水、兑换用户和过期时间
- 推广码、订单归因、待结算/可提现佣金和推广提现
- 会员等级、批发价、分销商供货等级与商品独立加价规则

## 分销与供货

- 分销商申请资料、信用额度、批发等级、钱包、提现和审核状态
- 独立域名、TLS 验证状态、站点品牌、主题、SEO 与客服配置模型
- 供货商加密凭证、独立 HMAC 协议客户端、商品映射和定时同步
- 采购单、外部订单、回调路由、轮询时间、成本和重试状态
- OpenAPI 商品、下单和订单查询，外部订单号数据库幂等

## 运营后台

- 经营看板、商品、规格、价格、库存、批次、订单、退款、支付、对账
- 用户、会员、钱包、礼品卡、推广、分销商、供应商、映射和采购
- 文章、公告、横幅、媒体、工单、通知、Webhook、风控与任务中心
- 管理员、角色、权限、TOTP、安全事件、登录日志、IP 黑名单和审计日志
- 所有模块使用 LinLinQi 原创黑白 UI，并支持深色/浅色切换和移动端布局

## 运维与可靠性

- API 与 Worker 独立进程、多优先级 Redis 队列、指数退避和唯一任务
- 订单过期定时调度、通知中继、Webhook 签名投递、供应同步、对账聚合
- Prometheus 指标、健康探针、优雅关闭、数据库连接池和严格生产配置验证
- PostgreSQL/Redis 持久卷、最小权限容器、只读 API/Worker 根文件系统
- CI 三端构建、Go test/vet、依赖安装和 Compose 配置检查

## 外部部署项

以下能力有完整连接端口和数据模型，但必须由运营方提供真实外部账户后才可能完成生产验收：支付机构商户号、通知中继、对象存储、域名与 TLS、上游供货商、监控告警接收端。仓库不包含第三方生产密钥。

## 供应链重构状态（2026-08-10）

- 已提供协议驱动的动态凭证表单、运行时可执行性门禁和只读连接健康探针；后台不会允许“注册表有名字但没有 driver”的协议冒充已支持。
- 已提供分类/商品快照、分类映射、字段级同步策略、批量导入、任务运行与 diff 查看，并本地镜像分类图、商品封面、图库和描述图片。
- 已统一 USD/CNY 等金额到 ISO 币种 + 最小单位 + 不可变 FX 快照；百分比使用 basis points，并支持百分比、固定金额和固定售价三种定价模式。
- 已固定每单供应商/映射/远端商品/参数/成本/汇率快照，并用数据库行锁和持久库存预占避免同一上游库存被并发订单重复出售。
- OpenAPI 已补齐余额、分类、商品、订单、币种/小数位、目录分页/增量和机器可读 3.1 契约。SMM 服务和 OTP 租号仍明确标为独立状态机待实现，不作为卡密自动采购能力宣传。
- 规格同步开关已闭环：拍平 SKU 协议自动建独立商品/映射/库存，嵌套规格协议自动建本地 SKU/变体映射并继承加价，上游规格消失自动停用本地变体；同步运行计数列已迁移统一为 `categories_created`/`products_created`。
- 风控页新增 7 日决策与安全事件趋势；`scripts/lobster-status.sh` 提供进程/数据库/Redis/存储/备份/风险待审/同步异常的只读汇总，处置边界见 [LOBSTER.md](LOBSTER.md)。
